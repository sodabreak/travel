## 克隆到 Windows

在 PowerShell 中运行：

```powershell
New-Item -ItemType Directory -Force -Path 'D:\ADD_WORK' | Out-Null
git clone https://github.com/sodabreak/travel.git 'D:\ADD_WORK\travel'
```

私密仓库需要使用有权访问的 GitHub 账号认证。克隆不会覆盖已有的非空目录。
