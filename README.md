# Travel · 长白山元旦三日计划

2027 年 1 月 1 日至 1 月 3 日，北京出发的长白山北坡与雾凇漂流行程。

## 本地查看

双击 `index.html` 即可打开网站。所有页面样式、路线示意与交互均包含在此文件中，不需要安装依赖。

也可在项目目录运行 `python -m http.server 8000`，再访问 `http://localhost:8000`。

## 内容

- 总览与路线示意
- 三天详细时间表
- 交通比较与住宿候选
- 预算切换与可勾选准备清单
- 天气备用安排与来源链接

资料核对日期：2026-11-14。元旦火车票尚未开售，车次为近期参考；住宿和漂流费用为规划预算，未预订。

## 克隆到 Windows

在 PowerShell 中运行：

```powershell
New-Item -ItemType Directory -Force -Path 'D:\ADD_WORK' | Out-Null
git clone https://github.com/sodabreak/travel.git 'D:\ADD_WORK\travel'
```

私密仓库需要使用有权访问的 GitHub 账号认证。克隆不会覆盖已有的非空目录。
